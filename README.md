# 스터디 봇 (Discord 출석·타임랭킹 봇)

디스코드 음성채널 출석을 자동으로 기록하고, 매주 스터디 타임랭킹을 정산하는 봇.

## 기능
- 지정 음성채널 입장/퇴장 스탬프 (임베드 카드)
- 24시(자정) 기준 개인별 일일 세션 트래킹 + 자정 요약
- 매주 수요일 오후 5시 Weekly 타임랭킹 (1~3등 메달, 출석/미출석, 정모 참석 예정)
- 정모 참석 체크(✅ 이모지)
- 데이터 JSON 저장 → 재시작에도 유지

## 명령어
| 명령어 | 설명 | 권한 |
|---|---|---|
| `!오늘` | 내 오늘 세션 기록 | 누구나 |
| `!현황` | 이번 주 타임랭킹 미리보기 | 누구나 |
| `!내순위` | 내 순위·누적시간 | 누구나 |
| `!정모현황` | 정모 참석 예정자 | 누구나 |
| `!정모체크` | 정모 참석 체크 메시지 게시 | 관리자 |
| `!리셋` | 주간 데이터 초기화 | 관리자 |
| `!시간추가 @멤버 분` | 주간 시간 수동 조정 | 관리자 |

## 설치 & 실행
```bash
pip install -r requirements.txt
cp .env.example .env      # .env 에 토큰 입력
python attendance_bot.py
```

## 설정 (attendance_bot.py 상단)
- `LOG_CHANNEL_NAME` : 스탬프/정산 채널 이름 (기본 "기록")
- `BOT_NICKNAME` : 서버 표시 별명 (기본 "스터디 봇")
- `VOICE_CHANNEL_IDS` / `VOICE_CHANNEL_NAMES` : 감지할 음성채널
- `COLOR_*` : 임베드 카드 색상
